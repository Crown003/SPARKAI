# AI Engine Context & Rules

This file serves as the specific context for the `ai-engine` module in the SPARK AI project.
As an AI agent operating in this folder, you must adhere strictly to these rules.

## 1. Tech Stack
- **Language:** Python 3.12+.
- **Orchestration:** LangGraph (for multi-agent workflows).
- **Task Queue:** Celery (listening to Redis).
- **Vector DB:** Qdrant (via `qdrant-client`).

## 2. Core Responsibilities
- This engine is responsible for taking the raw metrics and graphs generated by the `analysis-engine` and feeding them to Large Language Models.
- It generates vector embeddings and stores them in Qdrant for semantic retrieval.
- It produces the final, human-readable Engineering Readiness Report.

## 3. Strict Execution Rules
- **NO HTTP ENDPOINTS:** Do not create FastAPI or Flask servers here. This module is entirely asynchronous. It must ONLY execute tasks via Celery.
- **Isolate State:** LangGraph agents must not rely on local disk state. Store necessary graph states in Redis or Postgres via the backend APIs.
- **Dependency Management:** Use `uv` for managing `pyproject.toml` dependencies.
